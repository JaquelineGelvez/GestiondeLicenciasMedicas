# CHATBOT DE GESTIÓN DE LICENCIAS MÉDICAS

## Descripción

Este proyecto simula un chatbot para la gestión de solicitudes de licencias médicas dentro de una organización.

El sistema permite:

* Validar empleados.
* Registrar solicitudes de licencia.
* Verificar certificados médicos.
* Gestionar estados de solicitud.
* Registrar información en archivos CSV.

## Tecnologías utilizadas

* Python 3
* Visual Studio Code
* GitHub
* Archivos CSV
* BPMN 2.0
* Inteligencia Artifical

## Cómo ejecutar el proyecto

1. Descargar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Ejecutar el archivo main.py.
4. Seguir las instrucciones del chatbot.
